# GitCtrl · 极客控制台

> 基于 Electron + Node.js 的 Git 可视化桌面客户端。

## 功能特性

- 🟢 查看文件状态（已修改 / 未跟踪 / 已暂存）
- 🔵 一键暂存 / 取消暂存
- 🟣 图形化提交历史
- 🟡 分支管理（新建 / 切换 / 删除 / 合并）
- 🟠 实时差异查看（diff）
- 🔴 推送 / 拉取 / 获取

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Enter | 提交 |
| Ctrl + R | 刷新 |
| Ctrl + S | 暂存全部 |
| Ctrl + U | 取消暂存全部 |
| Esc | 关闭 diff / 关闭弹窗 |

## 测试用例

1. 修改本文件，观察文件状态栏出现 M 标记
2. 点击文件查看 diff，确认新增行显示绿色
3. 暂存文件，确认状态变为绿色 A
4. 输入提交信息并提交
5. 推送至远程仓库
